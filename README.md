# Personal Expense & Budget Tracker

A responsive personal finance tracking web application built entirely with **Vanilla JavaScript**, **HTML5**, and **CSS3**. It provides live balance calculations, category-based transaction ledgers, and dynamic entry filtering without external dependencies.

---

## 🚀 Live Demo
[View Live Demo](https://kamran934.github.io/personal-budget-tracker/)

---

## ✨ Features
- **Real-Time Financial Calculations**: Automatically recalculates total balance, total income, and total expenses whenever entries are added or removed.
- **Transaction Ledger**: Categorizes items into Income and Expense with distinct color-coded indicators.
- **Category Filtering**: Instant client-side display filtering (All, Income Only, Expenses Only) driven by HTML5 `data-*` attributes.
- **Defensive Form Validation**: Prevents invalid submissions such as empty text descriptions or zero/negative monetary values.
- **Dynamic DOM Architecture**: Leverages standard DOM manipulation methods (`createElement`, `appendChild`, and `remove`) to manage transaction items.

---

## 🛠️ Built With
- **JavaScript (ES6+)**: Custom DOM event listeners, array methods (`forEach`), data attributes (`dataset`), and numerical formatting (`toFixed`).
- **HTML5**: Semantic document structure and custom form inputs.
- **CSS3**: Modern Flexbox layout, responsive cards, and clean typography.
